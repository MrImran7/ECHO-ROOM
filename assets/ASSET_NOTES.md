All room illustrations are original procedural vector drawings in lib/game/room_art.dart.
The room JSON owns placement, visual variants and changes; there are no borrowed game assets.
The launcher icon is an original geometric doorway drawn for Echo Room.
All nine audio files are original synthesized PCM generated by tool/generate_audio.py.

To replace an object with a bitmap, add an `asset` path to its room definition,
add that folder to pubspec.yaml, and retain its normalized size and interaction
region. EchoGame preloads both before/after image assets once per room.
To replace sound, retain the cue filenames or replace AudioService.
